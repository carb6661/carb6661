## Engineering principles

- 以可运行的代码、清晰的 README、可复现实验和自动化验证交付项目。
- 对涉及数据或系统操作的功能，优先采用本地优先、最小权限、显式确认与可审计设计。
- 欢迎通过 Issue 提交使用反馈、Bug、文档改进或功能建议。
