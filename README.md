## Open-source principles

- 默认安全：最小权限、明确确认与不上传用户数据。
- 可验证：提供快速开始、示例、测试或可复现实验。
- 真实反馈优先：欢迎通过 Issue 提交使用体验、误报、文档改进或功能建议。
